# Deployment checklist

- [ ] MongoDB Atlas database created and network access configured
- [ ] Strong SESSION_SECRET configured
- [ ] Production domain configured in BASE_URL
- [ ] Secure cookies enabled
- [ ] Admin account created with seed script
- [ ] Daraja sandbox payment tested
- [ ] Callback URL tested over HTTPS
- [ ] Successful and failed callbacks tested
- [ ] Duplicate callback does not duplicate commissions
- [ ] Referral chain level 1 and level 2 verified
- [ ] Withdrawal available-balance check tested
- [ ] SMTP password reset email tested
- [ ] Persistent file storage configured
- [ ] Terms, privacy, refund and support pages published
- [ ] Kenyan legal/accounting review completed
- [ ] Production credentials added only as hosting environment variables
